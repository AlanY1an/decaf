# Decaf 0.3.2

- Fix the white/gray strip above Home and Settings: the title bar now matches the
  page and sidebar backgrounds in both light and dark mode.
- Keep the title bar in sync when the system appearance changes while a window
  is open. Update options, welcome and custom keep-awake windows use the same
  native background treatment.

On 0.3.1, choose **Settings → General → Check for Updates…**, then install and
relaunch. Earlier versions can update through the DMG or Homebrew. Your settings
and local usage history stay in place.

## 中文

修复 Home 和 Settings 顶部标题栏与页面背景不同色的问题，侧栏背景也延伸到窗口按钮
所在区域。浅色、深色及窗口打开时切换系统外观都会同步；更新说明、欢迎页和自定义
防休眠时长窗口的标题栏也统一了处理。

0.3.1 用户可以在 **Settings → General → Check for Updates…** 中下载、安装并重启。
更早版本可通过 DMG 或 Homebrew 升级。设置和本地用量记录保留。
