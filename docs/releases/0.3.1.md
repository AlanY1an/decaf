# Decaf 0.3.1

- Update directly from Decaf: choose **Check for Updates…** from the cup menu or **Settings → General**, then download, install and relaunch in the update window.
- Update packages and the release feed are signature-checked. Existing settings, integrations and local usage history are kept.
- Checks are initiated by you. No background checks, usage uploads or system profiling.

Versions 0.3.0 and earlier need one manual update to 0.3.1 via DMG or Homebrew before this feature is available. Future releases can use the in-app updater. If you prefer to manage Decaf with Homebrew, the existing commands remain available under **Update options…**.

## 中文

可以直接在 Decaf 里更新了：杯子菜单或 **Settings → General → Check for Updates…**，在更新窗口完成下载、安装和重启。更新包与更新信息均经过签名校验，原有设置、集成和用量记录保留。

仅在你主动点击时检查，不做后台检查，不上传用量。0.3.0 及更早版本需要先用 DMG 或 Homebrew 手动升级到 0.3.1 一次，之后的新版本就能在应用里更新。
