# Decaf 0.3.3

Switch accounts. Keep your conversations.

- **Move sessions** now lives in the sidebar, labeled **Claude Code**. The cup
  menu's **Move Claude Code sessions…** shortcut opens the same page.
- Select one or more source accounts and a destination. Local email and
  organization labels make accounts easier to recognize; missing labels can be
  added manually. Expand conversations to inspect available pin/group labels
  or leave individual sessions out.
- Review the exact move before Decaf quits and reopens Claude. Saved originals
  and per-session results support **Undo last** when the entries and history
  still match. Conversations changed afterward are preserved.

This first release supports **local Claude Code sessions in Claude Desktop
1.52386.3**. Sign in to the destination in Claude first. Other Desktop versions,
remote/scheduled sessions and ambiguous records are not moved. Pin/group
placement and per-session permission grants do not transfer. This does not
switch account credentials or migrate Codex sessions.

On 0.3.1 or later, choose **Settings → General → Check for Updates…**, then install
and relaunch. Earlier versions can use the DMG or Homebrew. Settings and local
usage history stay in place. [Move sessions guide](https://github.com/AlanY1an/decaf/blob/v0.3.3/docs/usage.md#move-sessions).

侧边栏新增 **Move sessions · Claude Code**：多选来源账号、指定目标账号，检查会话后
迁移。优先显示本地可验证的邮箱与组织；缺失邮箱可手动补充。可展开查看分组、置顶
标记并排除个别会话。菜单栏也有直接入口。

目前支持 **Claude Desktop 1.52386.3 中的本地 Claude Code 会话**。先在 Claude 登录
目标账号，Decaf 会在确认后正常退出并重开 Claude，保留原始记录及逐项结果。记录与
历史仍匹配时可以撤销；后续有改动的会话会保留并提示。分组、置顶和会话权限不随迁移
转移，不负责登录账号或迁移 Codex 会话。

0.3.1 及以后版本可通过 **Settings → General → Check for Updates…** 下载、安装并重启。
更早版本使用 DMG 或 Homebrew；设置与本地用量记录保留。
