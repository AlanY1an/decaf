# Decaf 0.4.0

Close the lid. Keep the agent running.

- **Keep Running with Lid Closed** is a new, opt-in switch in the cup menu and
  **Settings → General**. While Decaf is keeping your Mac awake for an agent or a
  manual hold, closing the lid no longer puts the Mac to sleep. With no hold
  running, closing the lid sleeps the Mac as usual.
- Turning it on shows a heat warning every time, unless you tick **Don't show this
  again**. Your Mac stays on and gets warm with the lid shut, so don't put it in a
  bag or a sleeve.
- The first time, macOS asks you to allow Decaf's helper under **System Settings →
  General → Login Items & Extensions → Allow in the Background**. The helper only
  changes the sleep setting during a hold.
- It turns itself off when the hold ends, below 20% battery, or if Decaf quits or
  stops responding. The cup shows a small laptop badge while it is in effect.

Choose **Settings → General → Check for Updates…**, then install and relaunch.
Settings and usage history stay in place. Versions before 0.3.1 can update using
the DMG or Homebrew.

## 中文

合上盖子，agent 照样跑。

- 菜单栏和 **Settings → General** 新增可选开关 **Keep Running with Lid Closed**。
  Decaf 正在为 agent 或手动保持唤醒时，合盖不会让 Mac 休眠；没有在保持唤醒时，
  合盖照常休眠。
- 每次打开都会提示发热风险，勾选 **Don't show this again** 后不再提示。合盖后 Mac
  持续运行并发热，请勿放进包里或电脑套里。
- 第一次使用时，macOS 会要求在 **系统设置 → 通用 → 登录项与扩展 → 允许在后台** 中
  允许 Decaf 的辅助程序。它只在保持唤醒期间修改睡眠设置。
- 保持唤醒结束、电量低于 20%、Decaf 退出或无响应时会自动关闭。生效期间，菜单栏
  杯子上会显示一个小笔记本图标。

通过 **Settings → General → Check for Updates…** 下载、安装并重启。设置和用量历史
都会保留。0.3.1 之前的版本可通过 DMG 或 Homebrew 更新。
