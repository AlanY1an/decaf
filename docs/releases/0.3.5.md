# Decaf 0.3.5

Keep moving your Claude Code conversations between accounts.

- **Claude updates no longer block moves just because the version changed.**
  Decaf checks local account identity, session records and transcripts before
  moving. Records it cannot verify stay in place with a reason shown in review.
- **Unblock a previous move after continuing a conversation.** If Undo cannot
  safely restore the old state, review the last move and choose **Keep here &
  continue**. Decaf verifies the current placement, preserves the latest history
  and lets you start another move. This also works with older saved operations.
- To move a conversation back, sign in to the next destination and start a new
  **Move**. The same conversation can go A → B → A with its latest history.
  Keeping a move ends Undo for that operation; it does not prevent future moves.

This feature supports local Claude Code sessions in Claude Desktop. Active,
remote, scheduled and conflicting sessions are still held with an explanation.

Choose **Settings → General → Check for Updates…**, then install and relaunch.
Settings, usage history and saved move records stay in place. Versions before
0.3.1 can update using the DMG or Homebrew.

## 中文

修复 Claude Code 会话在账号之间反复迁移时遇到的拦截。

- **不再因为 Claude 版本更新而禁止迁移。** Decaf 根据本地账号身份、会话记录和
  对话文件检查兼容性；无法验证的记录留在原处，并说明具体原因。
- **继续聊天后，旧迁移记录不再一直挡住下一次迁移。** 若 Undo 无法安全还原，
  查看上次迁移并选择 **Keep here & continue**。确认当前保存位置后，保留最新
  历史并允许继续迁移，也支持旧版留下的操作记录。
- 想换回原账号，在 Claude 登录下一个目标账号，再发起一次新的 **Move**。
  同一个会话可以 A → B → A，带着最新历史一起移动。保留上次迁移会结束该次
  操作的 Undo，不影响以后的迁移。

仅适用于 Claude Desktop 中的本地 Claude Code 会话；正在运行、远程、计划任务
以及存在冲突的会话仍会被跳过，并显示原因。

通过 **Settings → General → Check for Updates…** 下载、安装并重启。
设置、用量历史和迁移记录都会保留。0.3.1 之前的版本可通过 DMG 或 Homebrew 更新。
